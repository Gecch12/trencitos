# Sets de ambientes

Idea aceptada para pulir después, no para implementar ahora: un set coherente de
arte del tablero + reversos de cartas + piezas y sonidos compatibles. El reverso
aislado no es la prioridad. Puede tener valor en 2D; 3D ampliaría posibilidades.

## Hitos de definición

- [ ] Diseñar un set completo de ejemplo y sus componentes obligatorios/opcionales.
- [ ] Decidir qué ve cada jugador: ambiente local o compartido por anfitrión/sala.
- [ ] Verificar contraste, color de jugador y reconocimiento de rutas/cartas.
- [ ] Definir catálogo y fallbacks según capacidades/dispositivo.

## Evidencia y siguiente paso

Sin assets ni código. Primero definir experiencia compartida/local y un concepto
visual. Cambiar arte no cambia ciudades, rutas ni reglas; un mapa jugable distinto
se especificaría como otra funcionalidad. Ver [dirección](../decisions/product-direction.md).
